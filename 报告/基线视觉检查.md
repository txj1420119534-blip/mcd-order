# 本轮基线视觉检查

日期：2026-10-23（Asia/Singapore）。证据来自三业务 agent 在本轮源码改动前用真实 Chromium 捕获的当前页面；QA 已查看三张手机截图，未将此前报告图片冒充本轮截图。

1. 点餐首页与选餐长页：手机完整页约 5289 px。商品前有大幅概念主视觉、任务说明和设置块；商品卡是简化 SVG 食物，购物袋、优惠、任务与记录继续在页面下方铺开。功能入口存在，但真实点餐所需的商品浏览和交易上下文不够集中。优先改为简洁应用式头部、直接选餐、购物袋条和分步弹窗；必要规则在决策点显示。
2. 派对首页与偏好选择：手机完整页约 2846 px。已有场景概念图，但主题卡仍为小幅 SVG 图示，首屏大段内容与较长间距降低了直接选主题的效率。优先统一图片质量、精简文案、突出主题/人数/预算，并保留四步策划路径。
3. 游戏大厅：手机完整页约 3427 px。大场景图已有完成度，但三张实际游戏卡与游戏对象仍明显为几何绘制，造成主视觉与可玩的内容品质不一致。优先把实际游戏图形与大厅卡片改为同一套 raster 图片素材；布局控件和辅助反馈仍可使用基础 CSS/Canvas 效果。
