验收结果：**当前环境支持的 11 组浏览器检查全部通过，共 351 条断言。**正常流程没有未捕获 JavaScript 异常、图片加载失败或外部网络依赖。手机布局和最终真实截图已经人工目视检查。真实 `file://` 双击验收仍受云端浏览器策略阻断，未将其宣称为通过。

## 实际覆盖的操作

**点餐：**分类与搜索、带真实加载位图的商品详情、首次加餐自动提醒、领取任务、券后差额变化、会员门槛说明、保留原餐单、手机购物袋与结算弹层。核对了 ¥24.50 餐单距 ¥28 任务差 ¥3.50，使用 ¥4 商品券后差 ¥7.50；会员优惠按券后金额计算。未达标也能继续模拟下单；没领任务不会获得奖励；已领且达标才记一次下次甜点奖励，奖励不抵本单。还检查了门店不可用、显式演示身份切换、重置和弹窗焦点约束。

**派对：**主题变更先取消再确认，10 人与预算设置、按人数配餐、修改流程、进入完整方案；实际下载 TXT、独立 HTML 方案卡和 JSON 备份，并读取内容验证。结果保留“演示 / 未预约”边界；刷新继续保留方案，重置回到默认偏好。成人方案没有冒充官方儿童套餐预订。

**游戏：**合成实际投放、暂停和恢复；射击实际操控、炸弹次数变化、暂停和恢复；拼图通过实际格子点击完成解题、显示首胜结算、无重复入场扣费、只记一张模拟纪念券。测试了重试费用提示、全量重置、手机触摸、标记和刷新续玩。390 / 320 像素下默认显示完整九列；放大后触摸格宽至少 44 像素且可以横向滚动，再切回全盘。故意阻断食物图集时有明确错误、所有入口禁用、余额仍 888、未创建游戏；恢复资源并重试后才可开局，只扣一次 88 演示积分。

**数据与入口：**三个项目的所有历史查询页可读。无效 JSON 和显式模拟 401 业务结果导入失败时保留原快照；可解析的导入仍标记来源未经独立核验。总入口三个卡片、关于体验弹窗和项目子路径资源均可用。上述 401 是测试输入，不是真实 MCP 响应。

## 已知边界与待手测

1. **真实双击离线版尚待目标电脑确认。**本轮实际请求 `file://.../麦麦项目试玩/index.html`，Chromium 返回 `ERR_BLOCKED_BY_ADMINISTRATOR`；只读策略证据为 `/etc/chromium/policies/managed/urls.json` 默认阻断全部且未放行 file 协议。没有修改或绕过策略。替代检查仅在允许的 HTTP 文档来源上直接填充解压后的单文件字节，并阻断其余网络；这能验证资源自包含与交互，不等于真实 file 协议验收。
2. 本轮覆盖本地静态 HTTP 和项目子路径；**未验证公开域名、HTTPS 证书、CDN 或已部署网站**。可发布构建已经准备，不能把 localhost 检查表述为已获得公开分享链接。
3. 手机检查是 Chromium 视口与触摸模拟，尚未在实体 iPhone / Android、Safari 或 Windows / macOS 文件双击环境逐项手测。合成最终胜利和射击 58 秒首领通关没有作为本轮浏览器端到端完成项；不把拼图通关替代另外两款通关。
4. **没有新增实时 MCP 成功结果。**当前可调用工具中没有麦当劳业务工具；不带凭据的 initialize 探测在代理 CONNECT 阶段被 403 阻断，未取得业务 Schema。官方 README 提供结构化数据与商品图片字段，未提供完整官方网页导出能力。详见[官方只读参考与 MCP 边界](官方只读参考与MCP边界.md)。所有价格、奖励、成功回执与游戏积分继续为模拟或历史快照，不产生消费。
5. 本轮没有收集个人资料、内置个人凭据、增加跟踪统计，也没有通过浏览器测试执行真实下单、预订、发券或积分扣除。
