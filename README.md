# 麦麦点餐助手 · R2 候选

R1 交互原型加官方公开查询的时间戳快照。已有宿主 MCP 在本次验证中完成真实调用；静态网页使用采集结果，不直接调用 MCP，不自动刷新。页面顶部展开“官方公开查询参考”查看、筛选或导入快照。

## 运行

需要 Node.js 20+，无运行时依赖，无需 npm install。

```sh
npm start
# http://127.0.0.1:41860
# 如果端口占用：node server-r2.mjs --port 0 （自动选空闲端口）
npm test
npm run test:r2
npm run build
```

Windows 可双击 start.cmd；只监听 127.0.0.1。所有文件位于本项目内，未停止或修改其他项目。dist/ 可静态托管，交付没有发布。

真实快照：活动、上海人民广场示例门店、1450713 门店菜单、巨无霸 1 份报价 2550 分 = ¥25.50。购物车、单产品券、会员权益、实付门槛与未来奖励仍是固定演示；不使用真实快照提交订单。产品券与权益独立；未来奖励不抵本单；不强制加购。

所有快照均显示 UTC 采集时间；服务端 datetime 为 Asia/Shanghai。门店距离相对上海公开示例地点，不是用户定位。无账户、地址、订单查询；无下单、领券、抽奖、兑换或扣分。
